<h1>JavaScript Flashcards</h1>

A simple flashcard app built with HTML, CSS, and JavaScript. It lets you create, view and delete flashcards in your browser — no backend required.

You can try it out here: https://daniellejbs.github.io/javascriptflashcards/ 

<h2>Features</h2>
<ul>
  <li><strong>Create new flashcards:</strong> add a question and answer.</li>
  <li><strong>Delete cards:</strong> remove cards you no longer need.</li>
  <li><strong>Persistent storage:</strong> cards are saved in your browser using localStorage (so they stay even if you refresh).</li>
  <li><strong>Simple interface:</strong> easy to use, minimal design, mobile friendly.</li>
</ul>

<h2>How It Works</h2>
<ol>
  <li>Click New Card → enter your question and answer → save.</li>
  <li>Cards appear on the screen <strong>showing the question only.</strong></li>
  <li>Click on the card to reveal the answer in red!</li>
</ol>
You can remove cards with the Delete Card button and close the question box using the Close button.

<h2>Code Structure</h2>
<ul>
  <li>index.html — main HTML layout</li>
  <li>styles.css — basic styling for the app</li>
  <li>script.js — core logic: handling flashcard create, delete, and storage</li>
</ul>
